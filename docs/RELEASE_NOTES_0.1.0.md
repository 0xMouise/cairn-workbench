# Cairn Workbench 0.1.0 Preview

首个 Windows + WSL 本地安全研究工作台预览版。

## 已实现

- Windows Tauri 桌面端、托盘、窗口状态恢复、后台 WSL 保活及 NSIS 安装包。
- 中文工作区、深浅主题、命令面板、可调面板、活动日志、图谱与历史回放。
- 独立持久化项目与任务、OpenCode Server 适配、逐次审批、停止、显式新尝试。
- HAR/OpenAPI JSON 导入、范围与排除项校验、审批后 HTTP 重放。
- 加密请求身份、证据校验与跨项目隔离、发现复核、脱敏 Markdown/HTML/PDF 报告直接导出。
- WSL 手动项目终端、网络代理设置、脱敏诊断、旧数据导入、完整离线备份/恢复。

## 当前限制

- 默认免费 DeepSeek 的真实调用受服务商额度限制；完整模型驱动研究任务尚未通过验收。协议模拟通过不代表真实模型任务已完成。
- WSL 部署曾遇到服务响应超时，诊断信息与执行时限会保留；不会自动重试有副作用操作或转向付费模型。
- 此预览包未签名，未启用自动更新。稳定发布需要代码签名和独立的干净 Windows 环境验收。
- 本地运行沿用当前用户权限；审批不是操作系统沙箱。容器隔离、团队协作和跨平台桌面未包含在首版。
- PDF 包含中文排版与页码；原始 HTTP 响应和证据默认保存本机，分享报告前仍应复核内容。

## 验证记录

本机验证包含后端回归、模拟执行协议、真实本地 HTTP 重放、证据与报告浏览器流程，以及 Windows 编译与安装包生成。精确测试数量、截图与构建校验值以仓库中的验证记录和发布附件为准。
