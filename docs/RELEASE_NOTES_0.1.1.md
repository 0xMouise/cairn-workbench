# Cairn Workbench 0.1.1 Preview

这一版集中调整桌面界面的字体、配色与信息层级。

- 中文优先使用 Noto Sans SC，本机未安装时回退到微软雅黑 UI；统一正文、标题和标签的字重，减少小字与粗体。
- 浅色主题采用纸白、石灰色和低饱和绿；深色主题采用暖灰与浅鼠尾草绿。去掉蓝色强调和大面积纯黑白对比。
- 首页改为项目列表，移除大标语、宣传卡片和装饰性英文。无项目时收起详情栏，保留创建、搜索和设置入口。
- 点击「所有项目」「运行中」「已归档」可以返回对应项目列表，再打开项目继续工作。
- 图谱节点、连线、选中态和终端跟随主题；切换主题不会重启终端会话。
- 项目页空状态改为简短操作说明，统一按钮、输入框和正文的排版。

验证：前端 TypeScript / Vite 构建通过，3 条浏览器流程通过；包含项目列表往返、1280 像素窗口、图谱主题及终端连接期间切换主题。已检查 Windows 原生 WebView 的深浅主题截图。

本版沿用 0.1.0 的功能与模型限制：免费模型额度不保证；完整模型驱动研究任务尚未通过验收。安装包仍为未签名预览版，不包含自动更新。
